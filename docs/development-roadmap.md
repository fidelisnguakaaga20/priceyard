# Development Roadmap

Follow the approved stage sequence strictly:

0 Validation → 1 Project Setup → 2 Backend Foundation → 3 Database Foundation → 4 Authentication → 5 Subscription/Trial → 6 Admin Core → 7 Price Updates → 8 Search/History/Comparison → 9 Signals → 10 Buying/Sell-Watch → 11 Storage Suitability → 12 Costs → 13 Watchlist → 14 FAQ → 15 Feedback → 16 Audit → 17 CSV → **18 User Frontend (CURRENT)** → 19 Admin Frontend → 20 Access Testing → 21 Full Testing/Security → 22 Deployment → 23 Pilot → 24 Final Acceptance.

Only one stage may be active at a time unless the owner explicitly approves a change.

Stages 1 through 17 are completed/owner-approved under the execution gates. Stage 18 — Public and User Frontend MVP is the current stage. Stage 19 must not start until Stage 18 passes and receives owner approval.
