# PY-02 source publication safeguard - proposed local scope

Current rules: explicit source_1/source_2 identities are omitted from public price,
CSV and audit responses; legitimate Admin price management retains them. Public
price notes and generic source categories are already public. Market guidance
and premium intelligence retain their existing access rules. Free-text notes
could disclose a contact if an editor copies private material into them.

Recommended owner decision:
- Named sources/contact details belong only in the existing private source fields.
- Keep current public notes, generic source categories and premium access intact.
- Add a short hint beside the existing Admin Notes controls: "Shown to users.
  Keep source names and contact details in the private source fields."
- Verify the existing response allowlists for Guest/Free/Trial/Paid/Reporter/Admin,
  CSV, audit and share paths using fabricated private markers. Preserve Admin
  access, existing fields/design, all stored text and historical audit evidence.
- Do not guess which human names are confidential, silently edit historical notes,
  add fields, alter paid access or access production. Existing historical public
  text requires separate owner-authorized editorial review if necessary.

This is publishing guidance and disclosure prevention using the existing source
fields, not a claim that arbitrary confidential text can be identified perfectly.
Implementation is local only. The hint is visible and requires owner approval.

Decision: pending owner approval.
