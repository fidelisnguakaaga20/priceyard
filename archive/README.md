# Archive

Past work kept for the record. Nothing in this folder is used by the live app, the
automatic checks or the backups.

`local-test/` holds the one-off browser checks, recovery rehearsals and result records
(`local-test/evidence/`) produced while PriceYard was being built and hardened. File paths
written inside these scripts and records still refer to their original location,
`tools/local-test/`.

The checks that still run before every deploy live in `backend/tests`,
`frontend/tests/smoke` and `tools/local-test`.
