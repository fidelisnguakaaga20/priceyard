# Archive

Earlier work, kept for the record. Nothing in this folder is used by the live app,
the automatic checks or the backups.

| Folder | Contents |
|---|---|
| `PRICEYARD_PROGRESS.md` | The build log: each step, decision and test result while PriceYard was built and hardened |
| `docs/` | Earlier plans, approvals, reviews, release and recovery reports, and step-by-step evidence (`docs/evidence`, `docs/sql`) |
| `local-test/` | One-off browser checks, recovery rehearsals and their result records (`local-test/evidence`) |

File paths written inside these records may still refer to where the files were
originally kept (`docs/`, `tools/local-test/`).

The current documentation is in [`docs/`](../docs), and the checks that run before
every deploy are described in [testing](../docs/testing.md).
